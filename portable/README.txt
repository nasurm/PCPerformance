PC RADAR — PORTABLE WINDOWS APP

1. Extract the entire ZIP to a folder.
2. Double-click PC Radar.exe. Your default browser opens the local app.
3. Allow the first scan and online comparisons to finish.
4. Click Exit in the app when finished. Closing the browser alone does not stop it.

Windows 10/11 x64. No installation, administrator rights, or developer runtime needed.
Uses Windows PowerShell and .NET Framework already included with Windows.
Internet is required to download benchmark/game data the first time. Cached data works offline.
This is a requirements estimate, not a measurement of game FPS.

Your hardware, game paths and settings stay on your PC. Public game names and store IDs
are sent to Steam for lookup. Benchmark charts are downloaded from PassMark.
No telemetry, account, startup entry, system changes, or automatic updates.

Data is saved in the data folder beside the executable. If that folder is read-only,
the app uses %LOCALAPPDATA%\PC Radar instead and shows its location in Settings.
Settings includes Reset local data. Game files are never removed.
To remove the app: click Exit and delete its extracted folder; remove fallback data
at the location shown in Settings if applicable.

This launcher is unsigned. Windows may show an unfamiliar-app warning. No security
settings need to be disabled. Do not run a copy unless you trust who provided it.

Keep the app and runtime subfolders with the executable. No personal scan data or
third-party benchmark database is included in this ZIP. Node.js license notices
are included in runtime\LICENSE.
